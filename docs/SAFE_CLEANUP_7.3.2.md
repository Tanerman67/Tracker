# My Rhythm 7.3.2 - результат безопасной очистки

Дата: 24 октября 2026, Auckland. Статус: **локальный кандидат, не опубликован**.
Основа: Tanerman67/Tracker, main b9316f384ab63c84af1aca382b9b6b8058c69f2e (7.3.1). Перед завершением main повторно проверен; открытых PR не найдено.

## Изменения

- Today получил самостоятельную шапку с выбором даты. Мотивация, Experiments, English Activity, отдельный белок и недельная строка Today удалены из доступного интерфейса.
- Настройка карточек сохраняет старую конфигурацию, мягко пропускает архивные блоки и меняет порядок видимых карточек без потери размеров других. Для новой компоновки Energy Balance включён по умолчанию; существующая компоновка не переписывается.
- Nutrition сохраняет кольца КБЖУ, цели, редактирование и копирование дня. Частые продукты строятся только из фактических записей еды. Архивные favorites остаются в данных и не становятся приёмом пищи.
- Улица вводится обычным дневным значением. Детальные прогулки и рабочие блоки больше не редактируются; время сна и подъёма остаётся. Старые детали и неизвестные поля сохраняются.
- Body стал обычным экраном в Progress с явной кнопкой назад, восстановлением прокрутки и одной кнопкой добавления. График выбирает один показатель, затем показывает историю. Вес в logs и остальные замеры в bodyMeasurements остаются раздельными.
- Импорт защищает независимые разделы и настройки даже при пустых logs. Перед заменой создаёт локальную копию, доступную для скачивания. Конфликт, отказ записи и исключение не выдают сообщение об успехе; память сверяется с сохранённой версией, попытка импорта сохраняется как черновик.
- Экспорт помечается как подготовленный, без утверждения о сохранении в Files/iCloud. Старый lastExternalBackupAt сохраняется; новое поле lastExportPreparedAt не является подтверждением внешнего хранения.
- Для флага тренировки добавлен служебный energyWorkoutFlag только при автоматическом создании отметки. Удаление последней такой тренировки восстанавливает прежнее состояние, включая отсутствие, null и false. Ручная отметка true не сбрасывается; старые флаги без служебного поля не переосмысливаются.
- Body и backup выделены в body.js и backup.js. Основной app.js сокращён примерно вдвое. Удалены старый недельный экран и его эксклюзивные презентационные функции; общие расчёты/графики сохранены.
- Удалены стили выбранных старых интерфейсов; группа финальных Nutrition-правил перенесена из cleanup.css в nutrition.css. Остальные активные перекрытия оставлены до визуальной проверки.
- Версия кандидата 7.3.2, отдельный кэш ресурсов. Пути, origin, схема v3, primary/mirror, IndexedDB-vault, CacheStorage-vault и координация вкладок сохранены.

## Как продолжить проверку

1. npm ci
2. npx playwright install chromium webkit
3. npm test
4. npm run test:browser
5. npm run serve - ручная проверка интерфейса на http://localhost:8765

Не заменять существующий origin или путь приложения, не очищать данные браузера для обновления. Перед испытанием на реальном профиле скачать внешний backup и проверить файл. В репозитории и архиве нет личных резервных копий.

Публикация, push, merge и deployment в этой задаче не выполнялись. Нужна отдельная команда пользователя.
